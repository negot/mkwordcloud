# 異常検知

決定: CloudWatch の異常検知(Anomaly Detection)は設定しない。

## 理由

- 利用はワークショップの数時間に集中し、それ以外はほぼゼロになる。異常検知の学習に必要な、安定した平常時のデータが無い。
- 通知を設定しないため(alarms.md、[Q1])、異常検知のアラームを作っても、ダッシュボードで見るのと変わらない。
- 異常の確認は、ダッシュボードの「Lambda エラー数」「WebSocket エラー」「アラームの状態」で行う(dashboards.md)。

## 後から検討する場合

- 定期的に使うようになり、平常時のデータがたまってから、`WsHandler` の実行時間と WebSocket の ClientError に異常検知のバンドを設定する。
