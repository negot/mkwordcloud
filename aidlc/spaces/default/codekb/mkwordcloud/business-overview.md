# Business Overview

## Purpose
ワークショップ向けのリアルタイム・ワードクラウド。主催者がルームを作成して画面(スライド)に投影し、参加者はルームコードで参加して単語や短文を送る。送信テキストは語に分割・集計され、表示画面へ即時反映される。

## Roles
- **主催者(host)**: ルーム作成、表示画面(viewer)、リセット/終了(ホストキー必須)。
- **参加者(participant)**: Chrome 拡張機能のポップアップからルームコードで参加し、テキストを送信する。
- **viewer**: 表示画面の WebSocket 役割。

## Key Functionality
- ルーム作成(8 文字コード、24 時間で自動削除)
- テキスト送信(100 文字まで、レート制限あり)、語分割と集計、上位 100 語の表示
- 主催者によるリセット/終了

## Context for the Active Intent
拡張機能を使えない参加者(スマートフォン等)向けに、ブラウザで開く簡易入力フォームを追加する。ルームコードで参加する点は拡張機能と同じ。表示画面は変更しない(参照: feature-mobile-form.md)。技術的な接点は api-documentation.md と architecture.md を参照。
