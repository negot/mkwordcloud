ワードクラウドに参加する方法

Chrome の拡張機能から、単語や短い文を送ると、会場のスクリーンに表示されます

やることは3つだけです

  1. 拡張機能を Chrome に入れる(最初の1回だけ・約3分)
  2. スクリーンに出ているルームコードを入れて参加する
  3. 思いついた言葉を入力して送信する
名前やメールアドレスは不要です。送った文は、会場の画面に表示され、保存されて、24時間で消えます。送った人の名前は表示されません。

1準備するもの

  • パソコン版の Google Chrome(スマートフォンでは使えません)
  • 主催者から配られた wordcloud-extension.zip
会社が管理しているパソコンでは、拡張機能を追加できないことがあります。手順2の「デベロッパー モード」が選べない場合は、主催者に伝えてください。

2拡張機能を Chrome に入れる(最初の1回だけ)

  1. wordcloud-extension.zip をダブルクリックして展開(解凍)します。フォルダ wordcloud-extension ができます。
    Windows の場合は、右クリックして「すべて展開」を選びます。
  2. Chrome のアドレスバーに chrome://extensions と入力して Enter を押します。
  3. 画面右上の デベロッパー モード のスイッチをオンにします。
  4. 左上に出る パッケージ化されていない拡張機能を読み込む を押します。
  5. 手順1で展開したフォルダ(中に manifest.json が入っているフォルダ)を選びます。
  6. 一覧に「ワードクラウド送信」が出たら完了です。
  7. 使いやすくするため、Chrome 右上のパズルの形のアイコンを押し、「ワードクラウド送信」の横のピンを押して、ツールバーに固定します。
Chrome の起動時に「デベロッパー モードの拡張機能を無効にする」という案内が出ることがあります。この拡張機能を使っている間は、無効にしないでください。

3ルームに参加する

  1. ツールバーの「ワードクラウド送信」のアイコンを押します。
  2. ルームコードの欄に、スクリーンや案内に出ている8文字のコード(例: ABCD2345)を入力します。小文字で入れても大丈夫です。
  3. 参加 を押します。
  4. 入力欄と 送信 ボタンが出て、上に「接続済み」と表示されたら参加できています。
一度参加したルームコードは覚えておくので、次に開いたときは入力済みになっています。

4言葉を送る

  1. 入力欄に、単語や短い文を入れます(例: 「チームワーク」「楽しい」「新しい発見があった」)。
  2. 送信 を押すか、Enter を押します。
  3. 数秒以内に、会場のスクリーンのワードクラウドに反映されます。多くの人が送った言葉ほど大きく表示されます。
  • 1回に送れるのは 100文字までです。入力欄の下に残りの文字数が出ます。
  • 送れるのは 1秒に1回、1分に20回までです。
  • 日本語の文は自動で単語に分けられ、「は」「が」「です」などは表示されません。英語も使えます。
  • 自分が送った内容は、ポップアップの中にだけ表示されます。他の人の送信内容は見えません。
ワークショップにふさわしくない言葉は送らないでください。スクリーンに大きく映ります。

5こんなときは

表示されるメッセージ・状態どうすればよいか
ルームが終了したか、存在しません。ルームコードを見直してください。それでも参加できない場合は、主催者に新しいコードを確認してください。
送信が早すぎます。1秒以上あけてください。少し間をあけて、もう一度送ってください。
送信回数の上限(1分に20回)に達しました。1分ほど待ってから送ってください。
100文字以内で入力してください。文を短くしてください。
再接続しています…通信が一時的に切れています。自動でつながり直すので、そのまま待ってください。長く続く場合は、ポップアップを閉じて開き直してください。
ルームは終了しました。主催者がルームを終了しました。お疲れさまでした。
送ったのにスクリーンに出ない1文字だけのひらがなや、「は」「です」などの言葉は表示されません。内容のある言葉を入れてみてください。

6終わったら

  • ポップアップの右上の 退出 を押すと、ルームから抜けます。
  • 拡張機能が不要になったら、chrome://extensions で「ワードクラウド送信」の 削除 を押します。展開したフォルダも削除して構いません。
